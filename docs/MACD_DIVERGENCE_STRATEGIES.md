# MACD 顶背离策略研究记录

> 研究时间：2026-10-01 ~ 10-02。本文记录到目前为止**合格**的策略、它们的回测表现与过拟合评估，以及已经否掉的思路（避免重复测试）。
> 模拟盘实现见 `src/services/paper_trading/`，接口见 `docs/PAPER_TRADING_API.md`。

## 1. 合格标准

一个策略要同时满足以下条件才算合格：

1. **研究期**（2026-06-02 ~ 10-01，122 天）扣费后为正；
2. **样本外**（2025-12-14 ~ 2026-06-01，169 天，分 A 段 12/14~3/4、B 段 3/5~6/1）扣费后为正；
3. 阈值附近扰动（邻域）大多为正，不是靠单个参数点撑起来；
4. 比同条件下「创新高但无背离」的对照组明显更好（证明起作用的是背离）。

所有结果均扣 0.1% 往返手续费；信号时 24h 成交额 ≥10M；成交时止损距离 0.3%~10%。

## 2. 共同规则（所有合格策略的骨架）

| 环节 | 规则 |
|---|---|
| 峰 | MACD(12,26,9) 柱 = 2×(DIF−DEA)，连续红柱为一个峰 |
| 背离触发 | 当前峰内价格首次突破「前峰起点到本峰之前的最高价」，且前峰 DIF 峰值 >0 |
| 背离强度 | 触发K线 DIF / 前峰 DIF 峰值 **<0.6**；触发K线红柱 / 前峰红柱峰值 **<0.3** |
| 两峰之间 | 翻绿 **≥3 根**，绿柱最深处 ≥ 前峰红柱的 **20%** |
| 前波涨幅 | 前峰之前 60 根内最低点 → 新高，**≥20%**（部分策略 ≥30%） |
| 末段涨幅 | 两峰之间回调最低点 → 新高，**≥10%** |
| 反转K线 | 触发后 0~3 根内（含触发K线）出现阴线，且收盘 ≤ K线中点 |
| 入场 | **所有策略相同**：反转K线收盘后挂空单，**跌破反转K线低点成交**（跳空按开盘价）；有效 6 根（按策略周期），未成交前先破新高则撤单。若创新高那根本身就是反转K线，则以它的低点为入场价 |
| 止损 | 15m：新高；5m：新高 + 0.5×ATR14 |
| 止盈 | **固定 2R**；48 根未触及则按收盘价平仓 |
| 仓位 | 每笔固定风险（如 10U），qty = 风险 / \|止损 − 成交价\| |

**放量因子**（下文「+放量」）：`qv_surge` = 信号时刻 24h 成交额 ÷ 前一个 24h 成交额，**≥2**。

## 3. 合格策略一览

口径：1R = 账户 1%（如 1000U 账户每笔止损 10U），不复利；夏普按日盈亏（含无交易日）年化；回撤为已实现资金曲线。EV 括号为 bootstrap 90% 区间。

## 4. 过拟合评估

| 决策 | 怎么定的 | 风险 |
|---|---|---|
| 背离 + 反转K线 + 跌破低点入场、止损新高 | 用户的交易思路 | 低 |
| DIF比<0.6、红柱比<0.3 | 研究初期确定 | 中 |
| 前波≥20% & 末段≥10% | 研究期网格挑选，**已通过样本外验证** | 中 |
| 5m 止损 +0.5ATR、2R 止盈 | 研究期 17 种出场方式中挑选 | 中 |
| 放量≥2 | 30 个因子中挑选，用了全部数据；置换检验 z=3.28，刚过 95% 门槛 3.16 | **高** |
| 前波≥30%（S5） | 看过样本外后挑选 | **高** |

**现实预期**：只有 S1、S2 有干净的样本外。现规则从研究期到样本外缩水 35%~70%，S3~S5 上线后也应预期类似幅度的缩水。扣除额外滑点（急拉中止损单成交）、幸存者偏差（样本外补数只含现存币种）、多仓同涨同跌后，较合理的预期为 **每笔 +0.1~0.2R，按 1% 风险年化约 20~50%，夏普 1~2，最大回撤 10~20R**。

回测未覆盖的风险：
- 持续逼空的山寨季（10 个月内没有出现过）；
- 持仓期间的浮亏回撤（表中回撤只按平仓计算）；
- 2025-10 ~ 11 月无完整数据。

## 5. 已否掉的思路（不要重复测）

| 思路 | 结果 |
|---|---|
| 柱子翻转（DIF 下穿 DEA）后入场，止损极值 | 毛 EV≈0，背离与对照无差别 |
| 新高那根实时入场，止损极值外 0.5ATR | 15m 有弱优势，被反转K线口径全面超越 |
| 用「12 小时振幅 ≥p75」代替涨幅条件 | 研究期 +0.22R，样本外≈0 |
| 5m 止损正好放在新高 | 止损中位 0.85%，费用吃掉 ~0.12R，样本外≈0 |
| 用 ATR 倍数衡量拉升幅度 | 无效，5m 显著为负 |
| 底背离做多（5m / 15m） | 一致为负 |
| 1h 周期 | 样本不足 |
| 出场：1R/3R、保本、分批、跟踪止损、吊灯止损、斐波那契目标 | 都不如固定 2R（15m 用 1.5R 回撤最小） |
| BTC 4h 涨幅过滤（z=2.80 未过多重检验，且不采用）；因子：RSI、偏离 EMA20/50h 均线、反转K线影线/实体、触发/反转K线量比、新高超出幅度、连续背离、时段、周末、BTC 1h/24h | 与噪音无法区分 |

## 6. 数据与复现

- 数据：全市场 U 本位永续 5m（`kline_5m_YYYYMMDD`），2025-12-14 ~ 2026-10-01；2026-02 ~ 05 的缺口已于 2026-10-02 从币安回填入库。15m 由 5m 按 UTC 对齐聚合。
- 回测脚本与缓存（服务器 `/tmp/macd_div/`，可能被清）：`gen.js` 生成事件与因子，`an.js` 分桶统计，`fac*.js` 因子挖掘，`metrics.js` 年化/回撤/夏普。
- 实盘逻辑与回测一致性：`scripts/dev/verify/verify_paper_trading_parity.ts`（共同交易成交价/止损 100% 一致，R 差异中位 0.001）。

## 7. 下一步与停止标准

1. 模拟盘并行跑 S1、S2（已实现）与 S3、S4、S5（待实现）；
2. **停止标准（提前约定）**：某策略累计 100 笔后每笔 EV ≤0，即停止；
3. 实盘起步按 0.5% 风险，前向表现确认后再加。
